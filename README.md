# 🏛️ Kamran Cloth House — Premium E-Commerce Platform

> **Location:** Shafi Market, Saddar, Peshawar, KP, Pakistan  
> **Specialty:** Premium Men's Unstitched Fabrics, Dulha (Groom) Designs, Winter Collections, Coat & Waistcoat Fabric, Shawls.  
> **Aesthetic:** **Green & Gold** — deep forest green surfaces with gold accents and Playfair Display headings (see `DESIGN_SYSTEM.md`). Premium, traditional, trustworthy — never bazaar/discount.  
> **Sales Model:** Mobile-first Cash on Delivery (COD) + WhatsApp Direct Order. Cart, search, and multi-item checkout included.

---

## 📚 Project Documentation & Blueprint Files

To make building this project effortless for any developer or AI assistant, the complete system has been architected into modular specification files:

1. **[PRD.md](./PRD.md)**  
   *Product Requirements Document:* Feature specs, Green & Gold branding standards, 5-section homepage, 6-category catalogue, COD checkout flow, new pages, and admin self-management status.

2. **[DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md)**  
   *Design Authority:* Green & Gold palette, typography (Playfair Display + Outfit), component rules, and migration notes from the earlier Graceline direction.

3. **[TECH_STACK.md](./TECH_STACK.md)**  
   *Technology Decisions & Zero-Cost Architecture:* Why Next.js 16 + Neon was chosen over Shopify/WordPress to achieve 0 PKR/month hosting costs, sub-1.5s mobile speed, and complete customizability.

4. **[DATABASE_SCHEMA.md](./DATABASE_SCHEMA.md)**  
   *Database DDL & Data Models:* PostgreSQL (Neon) schema (Products, Brands, Categories, Banners, Orders, Settings) plus seed data for 30 Pakistani fabric brands and categories.

5. **[TRACKING_SPEC.md](./TRACKING_SPEC.md)**  
   *Meta & TikTok Pixel Tracking:* Event dispatch specifications (`PageView`, `ViewContent`, `AddToCart`, `Purchase`) for running high-ROI retargeting ads.

6. **[ROADMAP.md](./ROADMAP.md)**  
   *Phase-by-Phase Execution Plan:* Original 6 milestones (complete) **plus the Oct 2026 Rebrand workstream (R0–R8)** with live status.
